# Life3D LLM Context Pack

This folder stores the project context and handoff notes for LLM-assisted development.

Read these files in order:

1. `project-context.md` - product direction, current state, and important decisions.
2. `architecture.md` - subsystem map and key interfaces.
3. `build-test-package.md` - local commands, generated outputs, and environment notes.
4. `next-agent-handoff.md` - caveats, likely next tasks, and implementation guardrails.

The root project README is the user-facing summary. Files in this folder are intentionally more direct and implementation-oriented.
